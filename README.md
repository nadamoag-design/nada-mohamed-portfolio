# Nada Mohamed Mahmoud — Portfolio

A responsive personal portfolio for a Social Media Specialist & Media Buyer.

## Files
- `index.html` — semantic page structure, content, SEO metadata and contact links
- `styles.css` — responsive visual system, layouts, mobile navigation styling and reduced-motion support
- `script.js` — accessible mobile navigation, current year and subtle reveal effects

## Run locally
Open `index.html` in any modern browser. No build tools or package installation are required.

## Publish with GitHub Pages
1. Open the repository **Settings**.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then click **Save**.
5. Wait for GitHub Pages to finish deploying. The expected project URL is:
   `https://nadamoag-design.github.io/nada-mohamed-portfolio/`
